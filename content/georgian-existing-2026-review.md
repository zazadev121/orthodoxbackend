# Georgian translation review — existing content

The JSON adds Georgian (`_ka`) values only. It contains no writes to original Sorani, English, Kurmanji, IDs, publication state, author associations, source URLs or dates. It was authored and checked against the supplied content; no external machine-translation API was used. This is not a claim of independent human ecclesiastical approval.

## Editorial translation distinction

Prayer `10000000-0000-4000-8000-000000000008` is an existing OCA food-and-drink blessing. The Georgian before-meal prayer sources https://orthodoxy.ge/lotsvani/sazrdeli.htm and https://tveni.ge/pages/lotsva.php?gverdi=sazrdelis contain other established prayers, but the exact Georgian form of this particular OCA concluding blessing was not verified. At the parent’s request, the JSON supplies a faithful Georgian translation of the existing approved English wording, with `review_note_ka` explicitly explaining that it is an editorial translation and not text verified against an official Georgian prayer book. It is not a replacement prayer or an independently composed text. A clerical/editorial review remains appropriate before presenting it as an established Georgian liturgical form.

The source locators and inherited quotation attributions were preserved as supplied, not universally re-certified. New translations must not be represented as ancient Georgian quotations. Any displayed translation label should make editorial translation status clear.
